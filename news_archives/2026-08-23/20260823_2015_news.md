### 59. 告别 XP 时代旧设计，微软将为 Win11 现代化改造鼠标指示器功能
**发布时间:** Sun, 23 Aug 2026 03:39:03 GMT
**链接:** [https://www.ithome.com/0/993/165.htm](https://www.ithome.com/0/993/165.htm)
**正文:** IT之家 8 月 23 日消息，在上世纪 90 年代，如果你在 Windows 中找不到鼠标光标，通常只能依靠鼠标移动时留下的轨迹，通过来回移动鼠标来定位光标。进入 21 世纪初，微软增加了一项可以通过按下 Ctrl 键来寻找鼠标光标的功能，随着 Windows XP 的普及，这项功能也被越来越多的用户使用。此后，这项功能基本没有发生太大变化，但如今微软终于准备在 Windows 11 中对它进行现代化改造。如果你不熟悉这项功能，可以打开 Windows 设置，进入“辅助功能”，然后打开“鼠标指针与触控”页面，找到“鼠标指示器”选项并开启。现在按下 Ctrl 键，你会看到 Windows 通过一个圆形动画突出显示鼠标光标所在的位置。这项功能虽然偶尔会出现一些小问题，但总体来说足够实用，能够帮助用户快速找到鼠标光标。据IT之家了解，微软 PowerToys 也提供类似的功能，而且实用性更强。它会将整个屏幕调暗，只突出显示鼠标光标所在的区域，而且按下 Esc 键就可以关闭效果。如今，PhantomOfEarth 发现，微软似乎正在为 Windows 11 加入类似 PowerToys 的“鼠标指示器”体验，而且新版本采用了更加现代化的代码进行构建。新版“鼠标指示器”仍然可以通过 Ctrl 键启动，并将取代此前的旧版实现。除了外观更加美观、整体体验更加现代之外，新版还加入了一项可选功能“保持指示器可见，直到手动关闭”。这意味着，如果你按下的是 Win+Ctrl+Shift+M，而不是单独按 Ctrl 键，鼠标指示器就不会自动消失。只有再次按下这一快捷键、按下 Esc 键，或者点击屏幕将其隐藏后，指示器才会消失。此外，新版鼠标指示器的动画流畅度明显更高。随着微软继续完善这一功能，并逐渐接近正式版，动画效果很可能还会进一步提升。
